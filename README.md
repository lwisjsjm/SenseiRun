Sensei run is a cool game about a kung fu teacher trying to get to bed so he can scold his students effectively the next day. It's an attempt at a rage game so don't worry if you go through the floor, that is intended. Find the right path to get to the doors and finally be able to rest. Every level has a correct path, you just have to find it. Good luck and have fun trying to figure out what the real tiles and path is. :)
